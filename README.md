# Global Knowledge

Maintainer source for uDOS reference editions, standards and datasets. The installed baseline belongs in `~/Public/global-knowledge`; Shared and Vault overlays preserve personal changes separately. Canon curation belongs to the external Wizard/maintainer workflow.

This branch is a selective reconciliation proposal based on upstream, not a complete knowledge edition. Historical corpus and assets remain in `recovery/consolidation-2026-11-10`; neither their distribution rights nor their release readiness are established here. No installed baseline is changed by checking out this repository.

- [Layering and contribution contract](KNOWLEDGE_LAYERING_AND_CONTRIBUTION_SPEC.md)
- [Container semantics and capacity planning](standards/CONTAINER-STANDARDS.md)
- [Host reference contract](datasets/SOVEREIGN_HOST_REFERENCE.md)
